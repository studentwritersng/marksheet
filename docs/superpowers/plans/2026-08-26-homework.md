# Homework Feature Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a standalone Homework feature: teachers create class/subject homework with MCQ (≤20) and essay (≤5) questions (manual or from the question bank); students submit once (optional due date); MCQ auto-graded, essays manually marked; on publish, results notify guardians via push + email.

**Architecture:** Four new isolated Prisma tables (`Homework`, `HomeworkQuestion`, `HomeworkAttempt`, `HomeworkAnswer`) reusing the existing `QuestionType` enum and `Question` bank for content import, plus the existing `createNotification` pipeline for guardian alerts. Server actions mirror the Bursary `/fees` pattern (`ActionState` returns, `canManageFees`-style guards, audit + `revalidatePath`). No coupling to the exam/assessment engine.

**Tech Stack:** Next.js App Router, Prisma + PostgreSQL, shadcn/ui (existing), Vitest (unit tests), existing server-action + `createNotification` infra.

## Global Constraints

- MCQ questions cannot exceed **20**; essay questions cannot exceed **5** (enforced server-side, not just UI).
- One submission per student per homework (`@@unique([homeworkId, studentId])`); optional `dueDate` locks submission after it passes.
- MCQ are **auto-graded** on submit; essays are **manually marked** by the teacher; results are **published** by the teacher, which triggers guardian notification.
- Homework is **standalone** — reuses only the `Question` bank and `createNotification`; does not touch `LessonNote.assignment` or the exam/assessment engine.
- `createNotification` is called per guardian with `channel: "in_app"` (delivers push) AND `channel: "email"`.
- Verification gate: `npx tsc --noEmit 2>&1 | grep -v next.config.ts` must show 0 errors; `npx vitest run src/lib/homework` must pass.
- Local dev DB is unreachable this session; migrations are written and applied by `prisma migrate deploy` during the Vercel build. Do not expect to run the app live.

```ts
export interface McqOption {
  text: string;
  isCorrect: boolean;
}

export function autoGradeMcq(
  selectedIndex: number | null,
  options: McqOption[],
): { correct: boolean; scoreFactor: number } {
  if (selectedIndex === null) return { correct: false, scoreFactor: 0 };
  const chosen = options[selectedIndex];
  return { correct: !!chosen?.isCorrect, scoreFactor: chosen?.isCorrect ? 1 : 0 };
}

export function validateQuestionCounts(mcq: number, essay: number): void {
  if (mcq > 20) throw new Error("MCQ questions cannot exceed 20");
  if (essay > 5) throw new Error("Essay questions cannot exceed 5");
}

export function computeTotals(
  mcqScore: number,
  essayScore: number,
  totalMarks: number,
): { totalScore: number; percentage: number } {
  const totalScore = mcqScore + essayScore;
  const percentage = totalMarks > 0 ? Math.round((totalScore / totalMarks) * 1000) / 10 : 0;
  return { totalScore, percentage };
}
```

- [ ] **Step 1: Write `createHomeworkAction`**

Use the same auth/audit/revalidate pattern as `src/app/(app)/fees/actions.ts`. The form posts: `classId, subjectId, termId, title, instructions?, dueDate?, questions` (JSON string array of `{ type: "mcq"|"essay", text, marks, order, options?, rubric?, sourceQuestionId? }`).
```ts
"use server";
import { prisma } from "@/lib/prisma";
import { revalidatePath } from "next/cache";
import { z } from "zod";
import { validateQuestionCounts } from "@/lib/homework/grading";
import { recordAudit } from "@/lib/audit";
import { guardActiveLicense } from "@/lib/license";
import type { ActionState } from "@/lib/actions/types";
import { requireHomeworkManager } from "./auth";

const QuestionSchema = z.object({
  type: z.enum(["mcq", "essay"]),
  text: z.string().min(1),
  marks: z.coerce.number().min(0),
  order: z.number().int(),
  options: z.array(z.object({ text: z.string(), isCorrect: z.boolean() })).optional(),
  rubric: z.any().optional(),
  sourceQuestionId: z.string().optional(),
});

export async function createHomeworkAction(_prev: ActionState, fd: FormData): Promise<ActionState> {
  const ctx = await requireHomeworkManager();
  if (!ctx) return { error: "Not authorised." };
  try {
    await guardActiveLicense(ctx.schoolId);
  } catch {
    return { error: "Active license required." };
  }
  const classId = String(fd.get("classId") ?? "");
  const subjectId = String(fd.get("subjectId") ?? "");
  const termId = String(fd.get("termId") ?? "");
  const title = String(fd.get("title") ?? "").trim();
  const instructions = String(fd.get("instructions") ?? "").trim() || null;
  const dueDate = String(fd.get("dueDate") ?? "") || null;
  let questions: z.infer<typeof QuestionSchema>[] = [];
  try {
    questions = z.array(QuestionSchema).parse(JSON.parse(String(fd.get("questions") ?? "[]")));
  } catch {
    return { error: "Invalid question data." };
  }
  const mcq = questions.filter((q) => q.type === "mcq").length;
  const essay = questions.filter((q) => q.type === "essay").length;
  try {
    validateQuestionCounts(mcq, essay);
  } catch (e) {
    return { error: (e as Error).message };
  }
  if (!classId || !subjectId || !termId || !title) return { error: "Class, subject, term and title are required." };
  const homework = await prisma.homework.create({
    data: {
      schoolId: ctx.schoolId,
      classId,
      subjectId,
      termId,
      title,
      instructions,
      dueDate: dueDate ? new Date(dueDate) : null,
      createdBy: ctx.user.userId,
      questions: {
        create: questions.map((q) => ({
          type: q.type,
          text: q.text,
          marks: q.marks,
          order: q.order,
          options: q.options ?? undefined,
          rubric: q.rubric ?? undefined,
          sourceQuestionId: q.sourceQuestionId ?? null,
        })),
      },
    },
  });
  await recordAudit({ schoolId: ctx.schoolId, actorId: ctx.user.userId, action: "create", entityType: "homework", entityId: homework.id, afterValue: { title, mcq, essay } } as never);
  revalidatePath("/homework");
  return { success: "Homework created." };
}
```

```ts
export async function publishHomeworkAction(id: string): Promise<ActionState> {
```

- [ ] **Step 1: Write `submitHomeworkAction`**

```ts
"use server";
import { prisma } from "@/lib/prisma";
import { revalidatePath } from "next/cache";
import { autoGradeMcq } from "@/lib/homework/grading";
import type { ActionState } from "@/lib/actions/types";
import { requireStudentSelf } from "./auth";

export async function submitHomeworkAction(_prev: ActionState, fd: FormData): Promise<ActionState> {
  const ctx = await requireStudentSelf();
  if (!ctx) return { error: "Not signed in as student." };
  const homeworkId = String(fd.get("homeworkId") ?? "");
  const hw = await prisma.homework.findFirst({ where: { id: homeworkId, schoolId: ctx.schoolId }, include: { questions: true } });
  if (!hw || hw.status !== "published") return { error: "Homework not available." };
  if (hw.dueDate && new Date(hw.dueDate) < new Date()) return { error: "Submission closed (due date passed)." };
  const existing = await prisma.homeworkAttempt.findUnique({ where: { homeworkId_studentId: { homeworkId, studentId: ctx.studentId } } });
  if (existing && existing.status !== "in_progress") return { error: "You have already submitted." };

  const answersRaw = JSON.parse(String(fd.get("answers") ?? "[]")) as { questionId: string; selectedIndex: number | null; text: string }[];
  let mcqScore = 0;
  const answerData = hw.questions.map((q) => {
    const a = answersRaw.find((x) => x.questionId === q.id);
    if (q.type === "mcq") {
      const opts = (q.options as any) ?? [];
      const g = autoGradeMcq(a?.selectedIndex ?? null, opts);
      mcqScore += g.scoreFactor * q.marks;
      return { homeworkQuestionId: q.id, type: "mcq" as const, response: { selectedIndex: a?.selectedIndex ?? null }, autoCorrect: g.correct, autoScore: g.scoreFactor * q.marks };
    }
    return { homeworkQuestionId: q.id, type: "essay" as const, response: { text: a?.text ?? "" }, autoScore: 0 };
  });

  await prisma.homeworkAttempt.upsert({
    where: { homeworkId_studentId: { homeworkId, studentId: ctx.studentId } },
    create: { homeworkId, studentId: ctx.studentId, schoolId: ctx.schoolId, classId: hw.classId, termId: hw.termId, status: "submitted", mcqScore, submittedAt: new Date(), answers: { create: answerData } },
    update: { status: "submitted", mcqScore, submittedAt: new Date(), answers: { deleteMany: {}, create: answerData } },
  });
  revalidatePath("/student/homework");
  return { success: "Homework submitted." };
}
```

```ts
export async function publishResultsAction(homeworkId: string): Promise<ActionState> {
  const ctx = await requireHomeworkManager();
  if (!ctx) return { error: "Not authorised." };
  const hw = await prisma.homework.findFirst({ where: { id: homeworkId, schoolId: ctx.schoolId }, include: { questions: true, attempts: { where: { status: "graded" } } } });
  if (!hw) return { error: "Homework not found." };
  const totalMarks = hw.questions.reduce((s, q) => s + q.marks, 0);
  const students = hw.attempts.map((a) => a.studentId);
  const guardians = await prisma.guardian.findMany({ where: { studentId: { in: students }, schoolId: ctx.schoolId }, include: { student: true } });
  for (const g of guardians) {
    const att = hw.attempts.find((a) => a.studentId === g.studentId);
    if (!att) continue;
    const content = `${g.student?.firstName ?? "Your ward"} — ${hw.title}: ${att.totalScore}/${totalMarks} (${att.percentage}%)`;
    await createNotification({ schoolId: ctx.schoolId, recipientType: "parent", recipientId: g.parentUserId, recipientEmail: g.email, eventType: "homework_result", title: `Homework result: ${hw.title}`, content, channel: "in_app" });
    await createNotification({ schoolId: ctx.schoolId, recipientType: "parent", recipientId: g.parentUserId, recipientEmail: g.email, eventType: "homework_result", title: `Homework result: ${hw.title}`, content, channel: "email" });
  }
  await prisma.homeworkAttempt.updateMany({ where: { homeworkId, status: "graded" }, data: { published: true } });
  await prisma.homework.update({ where: { id: homeworkId }, data: { status: "closed" } });
  revalidatePath(`/homework/${homeworkId}/mark`);
  return { success: "Results published and guardians notified." };
}
```
