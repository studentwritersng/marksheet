# Marksheet — YouTube SEO Pack

**Channel:** Marksheet (Nigerian School Management Platform)
**Goal:** Rank for "school management software Nigeria", "Marksheet tutorial", and each feature name.
**Posting convention used below:**
- **Titles** — front-load the keyword, keep ≤ 100 characters, include "Marksheet" + year where natural.
- **Subtitles** — the supporting tagline/sub-headline shown under the title (also reusable as the video's first comment or pinned line).
- **Description** — keyword-rich first 2 lines (what shows in search preview), then value + timestamps + CTA + links.
- **Hashtags** — only the first 3 appear above the title; keep them tight.
- **Tags** — backend SEO keywords (mix of broad + long-tail).
